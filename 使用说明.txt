========================================
  LEO 卫星过境预报 · 离线版使用说明
========================================

【如何运行】
  无需安装任何环境（不需要 Node.js、不需要联网安装依赖）。
  双击本文件夹中的 Space.html，用浏览器（推荐 Edge / Chrome）打开即可。

【三种获取卫星 TLE 的方式】
  1. 手动粘贴 TLE / OMM —— 完全离线可用，始终有效。除 TLE 两行根数外，
     也可直接粘贴 OMM（CelesTrak / Space-Track 的 JSON 或 CSV），程序会自动
     合成两行根数；多颗可一次粘贴 JSON 数组或整段 CSV。
     编录号 ≥100000 且 CelesTrak 连不上时，这是唯一可用的方式：在能联网的
     机器/浏览器上打开
       https://celestrak.org/NORAD/elements/gp.php?CATNR=100465&FORMAT=JSON
     把返回的整段内容复制过来粘贴即可（把 100465 换成目标编录号）。
  2. 输入 NORAD 编号获取 —— 按"本地代理 → CelesTrak TLE → CelesTrak OMM(JSON)
     → 跨域 TLE API → 内置目录快照"依次尝试：
     · 手动发起更新时，联网可获取最新 TLE（无需 Node）；
     · 完全无网时才使用内置目录快照（tle_catalog.js，
       快照日期见该文件头部，共 16017 颗活跃卫星）；
     · 编录号 ≥100000 的新目标（2026-07-11 起入编）CelesTrak 已不再提供 TLE
       格式，程序会自动改取 OMM(JSON) 并合成两行根数。这类目标不在内置快照中，
       完全离线时无法获取，需联网。
  3. 卫星库搜索 —— 在"卫星库"面板输入别名 / 名称 / NORAD 编号搜索，
     点"选中匹配项"即可把目标卫星加入预报。
     （编号用十进制 100000 或 Alpha-5 的 A0000 任一种写法都能搜到）

【CelesTrak 连不上怎么办】
  若更新时提示各数据源「超时」，说明本机网络到 celestrak.org 不通（国内较常见，
  这时 5 位编录号的卫星其实一直是在用内置快照兜底，只是不容易察觉）。
  打开「卫星库」面板里的「⚙ 数据源设置」，填入任意返回 OMM 的数据源，程序会优先用它：
    · URL 模板中 {id} 换成十进制编录号，{key} 换成 API Key；
    · 已预填 KeepTrack 的模板（免费注册后可取 Key，限 500 次/小时、5000 次/天）：
        https://api.keeptrack.space/v4/sat/{id}/omm?apiKey={key}
    · 粘贴 Key 后点「保存数据源」，可先点「测试数据源」用 ISS #25544 验证连通性。
  模板含 {key} 时 Key 放在 URL 里（file:// 打开不会触发跨域预检，更容易连通）；
  不含则自动改用 X-API-Key 请求头。
  API Key 仅存本机浏览器，不写入任何文件，因此整个文件夹仍可安全分享给别人。

【功能速览】
  · 顶部菜单：一级菜单「过境预报 / 工具」，点「工具」在下拉二级菜单中选
    「天线指标测试工具」，即可整屏切换到天线测试计算器，点「过境预报」切回
  · 天线指标测试工具（已并入本页）：天线增益（波束宽度法）、系统噪温（Y 因子法）、
    G/T 品质因数、EIRP、指向精度（20 组逐组录入，下方列表累计显示并可删除重录）、
    频谱仪操作指南、测试记录（可存本机并导出）
  · 多站址管理：可添加多个观测站址并勾选参与预报
  · 卫星库：可为每颗卫星自由命名分组，并按分组筛选、搜索或批量选中；
    点击卫星行展开查看 TLE 两行根数（含历元、更新时间，
    可一键复制）；可手工记录数传旋向（左旋/右旋）、遥测旋向（左旋/右旋）
    以及数传频点、遥测频点（MHz）；支持按别名/名称/NORAD 编号/分组搜索
  · TLE 手动更新：可更新全部卫星、当前勾选的目标卫星，或展开单颗卫星后单独更新；
    更新在后台执行，预报始终可直接使用本地已保存的 TLE
  · 预报参数：预测时长可选；可设置"最高仰角 ≥ X°"过滤，
    只显示最高仰角不低于该角度的过境窗口
  · 过境窗口：多卫星多站址合并后按入境时间先后排序
  · 可视化：方位轨迹图（天空方位/仰角）+ 仰角变化曲线，可播放过境动画
  · 导出：过境窗口可导出为 Excel（.xlsx）表格
  · 数据保存在浏览器本地（localStorage），关闭网页不丢失

【注意】
  · 页面加载后默认使用本地已保存的 TLE，不会自动刷新；只有在手动更新时才会尝试联网，
    完全断网时会回退到目录快照（快照会随时间老化，轨道精度下降）。
  · 关于 NORAD 编录号的两种写法：编录号超过 99999 后，TLE 的 5 列固定字宽装不下
    6 位数字，首字符改用字母表示（A=100000、B=110000……依次类推，跳过字母 I 和 O，
    即 A0000=100000、Z9999=339999）。添加、搜索、更新时两种写法（100000 / A0000）
    都可直接使用，程序内部统一按十进制处理；TLE 两行根数里显示的仍是字母形式。
    超过 339999 的编录号无法写入 TLE，程序会明确报错而不是悄悄算错。
  · 若某颗卫星更新失败，提示里会列出「各数据源尝试结果」（本地代理 / CelesTrak TLE /
    CelesTrak OMM / 第三方 API 分别失败在哪一步）。需要更详细的排查时，按 F12 打开
    浏览器控制台，执行 diagTLE('A0465')（编录号任意写法），会逐个数据源打印真实
    HTTP 状态、耗时和响应内容，便于区分「跨域被拦」「连不通/超时」「无数据」「字段名不符」。
  · 某个数据源一旦超时，本次会话内会跳过它（结果注定一样，避免每次都耗满超时拖慢
    「更新全部」）。重新联网后若想再试，在控制台执行 resetTLESources() 即可恢复。
  · 即使 TLE 手动更新尚未完成，也可立即开始预报；本轮计算会固定使用启动预报时的本地 TLE。
  · 文件清单：Space.html（主页面，天线指标测试工具已并入其中）、
    lib/（卫星轨道计算与 Excel 库）、tle_catalog.js（内置 TLE 目录快照）、
    README.md（项目说明）。请保持相对位置不变。
