模块 2 · 天线系统噪温测试 Tsys

Y 因子法（P1/P2 测量法，含 LNA 修正）：实测热负载、冷空间两组噪声功率 P1、P2，扣除 LNA 噪声温度后得到天馈系统噪温，进而合成系统总噪温。

Y = 10^((P1 − P2)/10)；Tan = (T0 + TLNA)/Y − TLNA；Tsys = Tan + TLNA；Tsys (dBK) = 10·lg Tsys
输入参数

测量步骤：① 馈源使用吸波材料，频谱仪读数记为 P1；② 馈源不使用吸波材料，读数记为 P2。P1、P2 需使用同一单位。T0 为常温负载的噪声温度（K），TLNA 为低噪声放大器的噪声温度（K，按器件手册手动输入）。

模块 5 · 天线指向精度测试 δP

对 n 组方位/俯仰实测角度（大纲按 20 组设计）做均方根误差统计：先求平均角度，再求方位/俯仰 RMS 误差，最后合成综合指向误差。

模块 6 · 频谱仪实测操作与设置指导

摘自《天线性能测试计算 APP 综合大纲-最终版》第四节，供外场测试时参考。

① 频谱仪实测配置规范表
测试项目 RBW 设置 VBW 设置 检波器模式 衰减器 (RF Atten) 前置放大器 (Preamp) Trace 模式 特殊功能建议
3dB/10dB 波束宽度 10 kHz ~ 100 kHz ≥ 3 × RBW Peak 或 Auto 10 dB（自动） OFF / Auto Max Hold 开启 Delta Marker
噪温 P1、P2 测量 1 MHz 10 Hz ~ 100 Hz RMS（均方根）或 Sample 0 dB ON（开启） Video Avg（50 次） 开启 Marker Noise（dBm/Hz）
EIRP 远场测功率 100 kHz ~ 1 MHz ≥ 3 × RBW Peak 或 RMS 防过载适度设置 根据信号强度 Clear Write / Avg Peak Search 锁峰
② 操作要点
  • 波束宽度：中心频率设为信源频率；对准最高点设 Marker 1 为参考点，开启 Delta Marker，记录功率下降 3.0 dB 与 10.0 dB 时两端角度差值，即为 AZ₃/EL₃/AZ₁₀/EL₁₀。
  • 噪温：Preamp ON、衰减 0 dB、RMS 检波；天线接常温匹配负载读数为 P1，指向天顶冷空间读数为 P2；建议 Marker Noise 直接读取 dBm/Hz。
  • EIRP：Peak Search 锁峰后读取功率，记录收发距离与频率用于 FSPL 反算。
